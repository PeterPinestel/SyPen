# Amazon content workflow

- For product research and listing copy, use the installed `$amazon-listing-research` plugin skill when available. Save a product fact ledger and approved message plan before visual production.
- For secondary images, A+, Brand Story, or adapting an existing stack, use `.agents/skills/amazon-image-production/SKILL.md`. Its source hierarchy and visual QA rules apply to every variant.
- Treat all prior generated outputs as historical work, never as authoritative product references. A new product or variant requires its own fact ledger and actual-product references.
- Save individual deliverable images in descriptive product folders, retain a concise manifest, and verify that linked GitHub files open. Keep drafts distinct from approved assets.
